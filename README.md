# Minha Loja — catálogo

Este repositório guarda o catálogo da loja **Minha Loja**.

- `catalog.json` — lista de apps e sites que aparecem na loja. Edite aqui e toque em ⟳ na loja.
- Ícones e capturas de tela podem ficar nesta pasta (use o nome do arquivo no catalog.json).
- Os arquivos `.apk` ficam em **Releases**.

Baixe a loja: https://github.com/Lingua-Byte/minha-loja/releases/latest/download/MinhaLoja.apk
